# 测评结果与疑问反馈：界面用词调整

2026-10-15。课堂抽查使用“测评”称谓，界面强调等级与作答反馈。保留现有分数展示、等级规则、发布门禁、疑问提交期限和复核流程；学生填写框的现有标签、占位提示及教师自定义提示内容不变。
