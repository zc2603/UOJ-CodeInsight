# 界面设计与合成浏览器验证

更新：2026-09-29；2026-10-02 补充第二阶段（申诉期限与运行参数／模型自动测试）的验证记录。

## 本轮界面

- 统一墨绿色主色、白色卡片、留白、标题层级、主次按钮与键盘焦点。
- 学生成绩页区分读取中、读取失败、等待公布、未参加及已公布状态；已公布页面按总分、本人答案、参考答案、评分反馈和复核申请分区。
- 学生成绩概览左侧显示等级，右侧显示原始总分／实际满分和完成时间，不再显示百分制。学生与教师共用等级规则：9–10 分 A+、7–8 分 A、5–6 分 B+、3–4 分 B、1–2 分 C、0 分 D；例如 6 / 6 分为 B+，不按满分比例换算。浏览器检查覆盖 0–10 各整数分及 6 / 6 的情形。
- 教师测评管理列表与结果概览显示平均原始分，学生表格用“等级”替代“百分制”。`GET /api/admin/quizzes` 的 `average_score` 表示当前轮次已完成、无需复核且分数完整的有效原始分均值；人工分优先，零分计入，未评分／待复核／旧轮次不计入，无有效分时为 null。等级对未完成或待复核记录显示“—”。后端合成检查覆盖不同满分、零分、逐题人工分、总分覆盖、缺失分数及新旧轮次。
- 自由作答页按原题分组导航，明确简答／单选及作答状态；修正导航行布局、单选／复选框尺寸，保持独立代码滚动区。
- 交卷采用与教师端一致的确认弹窗，支持 Tab 焦点循环、Escape 取消及关闭后恢复焦点。
- 教师列表、创建、题目预览、作答详情、成绩与申诉页面使用一致的卡片与响应式规则；移除作答详情中重复显示的一组选项。
- 学生入口、完成页与历史顺序作答页兼容窄窗口。
- 请求标识在 HTTPS 和普通 HTTP 下均可生成；整份交卷重试保留同一个标识，新协议不调用旧草稿接口。

## 已验证范围

Chrome，1366×768、900×768、390×844。全部 API 由浏览器测试拦截为合成数据，无 UOJ、生产数据库或模型请求。

验证包括：学生登录、开始、简答草稿、切题回看、标记撤销、键盘题号导航与单选、清空选择、交卷确认与失败重试、完成页、等待公布、已公布、未参加、错误提示、学生复核申请；教师登录、列表、导入预览、时长调整、搜索、成绩、申诉弹窗、展开题面／代码、作答详情、预生成详情及编辑弹窗。历史顺序作答页面也做了输入与布局检查。

自动断言页面无横向溢出、浏览器无未捕获异常、导航不遮挡答题区、桌面代码可以滚动到底、确认和申诉弹窗的键盘焦点留在弹窗内。截图使用合成内容，保存在本地证据目录，人工检查代表性页面。

这些检查覆盖页面呈现与合成交互，不替代真实后端权限／并发测试，也不代表所有浏览器或完整无障碍审核。

## 运行

在 `frontend` 目录中，安装项目现有依赖后：

```text
npm run build
npm run test:student
npm run test:statement
npm run test:interface
```

`test:interface` 需要本机 Chrome 和 Playwright。若 Playwright 安装在独立工具目录，通过 `PLAYWRIGHT_MODULE` 指定其模块路径；测试不会自动安装或改写项目依赖。`UI_EVIDENCE_DIR` 可指定截图目录，默认使用项目的本地 `artifacts/ui-refresh-20260929/`。

可设置 `UI_ASSETS_ORIGIN`，从指定站点只读获取实际静态资源，与本地构建逐字节比较，再在隔离的 HTTP 合成页面执行同一套检查。业务 API 仍全部拦截，不会登录真实账户或提交真实作答。
