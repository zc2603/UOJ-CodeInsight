# 定时开放

在测评管理的课前准备卡片中，点击「定时开放」，选择北京时间并确认。弹窗会显示本场进入窗口及最后进入时间。列表的「更多操作」也提供同一入口。

- 可以在出题过程中预约，关闭教师网页后仍由服务器执行。
- 预约后可修改时间或取消；「立即开放」成功后会清除预约。
- 到点只有全部题目就绪才会开放；否则显示「定时开放失败」及原因，由教师处理后重新预约或手动开放。
- 后台每 2 秒检查一次。进入窗口从预约时间计算；重启后若仍在窗口内，开放剩余时间，若整个窗口已过则标记失败。
- 个人作答时间仍从学生开始作答时独立计算。

实现使用数据库持久字段与行锁，迁移为 `0011_scheduled_open`。已存在的测评没有默认预约，不会自动开放。

验证：后端合成测试覆盖到点开放、固定窗口、重复扫描、未就绪失败、重新预约、取消、立即开放、过期窗口与非法时间；浏览器三种尺寸检查预约、修改、取消、北京时间转换及弹窗键盘操作。SQLite 迁移升级／回退／再升级通过。本轮未运行独立 PostgreSQL 并发专项。
